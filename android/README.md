# App LSC 4 versiones (Android)

Proyecto de Android Studio de la app del celular. Ver el README principal del repositorio.

- Las 4 versiones en ONNX: app/src/main/assets (las genera codigo/exportar_celular.py).
- Las 90 senas (muneco y video): app/src/main/assets/aprender (las genera codigo/preparar_mostrar.py).
- Prueba de que el calculo del celular es igual al de Python: app/src/test (CalculoTest).
